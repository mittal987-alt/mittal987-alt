An AI coding assistant designed around multi-agent workflows for code planning, editing, AST-driven debugging, and pull-request reviews. Includes code indexing and vector retrieval, an embedded Monaco editor, and isolated Docker execution environments.

**Tech:** Next.js · Python · LangGraph · Qdrant · RAG · Docker · Kubernetes

**Tech:** Next.js · Node.js · MongoDB · Socket.IO · AI services

**Tech:** React · FastAPI · LangGraph · LangChain · SQLite
