I build end-to-end software, from polished frontends and APIs to LLM-powered applications, and I'm working toward a career as an **AI/ML engineer**.

## 🚀 Featured projects

### 🛍️ [Bazari](https://github.com/mittal987-alt/bazari)
A peer-to-peer marketplace built for India.
Listing discovery, location-aware search, saved ads, and real-time chat.
**Stack:** Next.js · TypeScript · MongoDB

### 🤖 [Coding Agent](https://github.com/mittal987-alt/coding_agent)
An AI software-engineering assistant that combines retrieval with local and cloud model workflows to help with code understanding and generation.
**Stack:** Python · FastAPI · LangGraph · RAG · Docker

### 🔬 ResearchMind
A multi-agent research pipeline where cooperating LangChain agents search, gather, and synthesize information into structured research output.
**Stack:** Python · LangChain · Streamlit

### 💸 Finance AI Coach
A personal-finance dashboard with bank-statement analysis, transaction categorization, spending insights, goal planning, and an AI chat interface.
**Stack:** React · TypeScript · FastAPI · PostgreSQL · SQLAlchemy

### 🏃 FitQuest
A Flutter fitness game where walking captures territory, with live map tracking, fitness stats, and leaderboards.
**Stack:** Flutter · Dart · Google Maps · Firebase
