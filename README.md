A marketplace project built with **Next.js, TypeScript, and MongoDB**. Work has included listing discovery, location-aware search, saved ads, and real-time chat.

**Focus areas:** full-stack development · search and filtering · geospatial data · marketplace workflows

### 🤖 [Coding Agent](https://github.com/mittal987-alt/coding_agent)
An AI software-engineering assistant project exploring **Python, FastAPI, LangGraph, retrieval, local/cloud model workflows, and developer tooling**.

**Focus areas:** AI agents · RAG · code assistance · backend architecture · Docker-based deployment

### 🏃 FitQuest
A Flutter fitness game concept where walking can be used to capture territory, with map tracking, fitness statistics, and leaderboards.

**Focus areas:** Flutter · Google Maps · geolocation · Firebase

### 💸 Finance AI Coach
A personal-finance application concept with bank-statement analysis, transaction categorization, spending insights, goal planning, and an AI chat interface.

**Focus areas:** FastAPI · PostgreSQL · SQLAlchemy · PDF processing · AI-assisted insights
